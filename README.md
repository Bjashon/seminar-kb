# Seminar KB

База знаний по материалам семинаров (7 сезонов, таблицы статей в Notion):
определения, теоремы, свойства, задачи — связанные между собой, на русском
и английском.

Отдельный проект, без связи с Draftea (ни по коду, ни по оформлению).
Возможно совместное размещение на том же сервере (EasyPanel), но отдельная
БД и отдельный деплой.

## Цель

- Поиск в одну строку (как в Google), на любом из двух языков — сразу выдаёт
  нужные определения/теоремы/свойства с LaTeX-версткой.
- Внутри карточки — ссылки на определения, которые она использует, и обратные
  ссылки на то, где она используется.
- История поисковых запросов пользователя.
- Карточки для интервального повторения (SRS), в первую очередь по темам,
  которые всплывали в поиске.

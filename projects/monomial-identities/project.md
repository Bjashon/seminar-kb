# Скобочные тождества (задача 2.6)

## О проекте

Файлы проекта — в репозитории, папка `projects/monomial-identities/`: `lecture.html` и `lecture.json` (курс), `checks/` (скрипты и таблица `atlas.json`). Для скриптов нужен пакет `python-flint`.

## Постановка задачи

Скобочный одночлен — выражение вида $[[x_1,x_2],[x_3,x_4]]$: каждая буква один раз, скобки расставлены полностью. Его форма $\sigma$ — неупорядоченное бинарное дерево (буквы стёрты, порядок детей не важен). Одночлен формы $\sigma$ обозначается $w_\sigma$.

**Гипотеза.** Если тождества $w_\sigma=0$ и $w_\tau=0$ равносильны в классе алгебр Ли, то $\sigma=\tau$.

В тетради условие записано как «одночлены равны в свободном коммутативном неассоциативном группоиде»; читать это нужно с точностью до переименования букв, иначе утверждение неверно уже при $n=3$.

Три равносильных вида гипотезы:

1. Идеалы. Пусть $F$ — свободная алгебра Ли, $I_\sigma$ — оболочка значений $w_\sigma$; тогда $I_x=F$, $I_{[\alpha,\beta]}=[I_\alpha,I_\beta]$. Гипотеза: разные формы дают разные идеалы. Иначе: подгруппоид идеалов, порождённый $F$ относительно $(A,B)\mapsto[A,B]$, свободен.
2. Однозначность разложения: из $[A,B]=[C,D]$ для идеалов вида $I_\sigma$ следует $\{A,B\}=\{C,D\}$.
3. Подпространства. Пусть $M_\sigma\subseteq\mathrm{Lie}(n)$ — оболочка всех одночленов формы $\sigma$ в полилинейной части. Тождество $w_\tau=0$ следует из $w_\sigma=0$ тогда и только тогда, когда $M_\tau\subseteq M_\sigma$. Гипотеза: подпространства разных форм различны.

## Что известно

- Задача стоит в тетради без отметки о решении. Поиск в открытом доступе решения не дал; MathSciNet и zbMATH не проверены.
- Счёт: для всех $n\le8$ (форм 1, 1, 2, 3, 6, 11, 23) подпространства $M_\sigma$ попарно различны. Размерности при этом иногда совпадают (при $n=6$ две формы с 75, при $n=8$ четыре таких пары).
- Шаг Якоби: поддерево $[[a,b],c]$ заменяется парой $[[a,c],b]$, $[a,[b,c]]$; получаются формы $\tau_1,\tau_2$ с $I_\sigma\subseteq I_{\tau_1}+I_{\tau_2}$. Отсюда отношение выводимости $\sigma\preceq\rho$, и из $\sigma\preceq\rho$ следует $M_\sigma\subseteq M_\rho$.
- Наблюдение J1: для $n\le8$ все включения $M_\sigma\subseteq M_\rho$ выводятся шагами Якоби (следований 1, 3, 9, 28, 90 при $n=4,\dots,8$ — столько же, сколько выводимых).
- Наблюдение J2: для $n\le17$ никакие две разные формы не выводятся друг из друга. J1 и J2 вместе дают гипотезу.
- Инварианты формы, читаемые по $M_\sigma$: высота дерева (через теорему Пуанкаре–Биркгофа–Витта, доказано) и число Стралера (номер последнего члена производного ряда, содержащего $I_\sigma$; есть набросок доказательства).

Точность счёта: при $n\le6$ ранги посчитаны точно и сверены с полным перебором расстановок букв; при $n=7,8$ — по модулю простых $2^{61}-1$ и $2^{31}-1$.

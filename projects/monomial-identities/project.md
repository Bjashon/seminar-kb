# Скобочные тождества (задача 2.6)

## О проекте

Задача 2.6 из «Днестровской тетради» (Ю. А. Бахтурин; 4-е издание, 1993): разные расстановки скобок на $x_1,\dots,x_n$ задают разные тождества алгебр Ли. Рабочая страница проекта: постановка, что известно, план, журнал. Обсуждение идёт в чате, итог записывается сюда.

Подробное объяснение — в курсе по кнопке «План-курс по задаче» над этой страницей: 10 модулей с вопросами, подсказками, атласом форм до 8 букв и калькулятором скобок.

Файлы проекта — в репозитории, папка `projects/monomial-identities/`: `lecture.html` и `lecture.json` (курс), `checks/` (скрипты, таблица следований `atlas.json`, сертификаты `thin_certificates.json`). Скриптам с рангами нужен пакет `python-flint`; `thin_search.py` и `thin_invariants.py` обходятся без него.

## Постановка задачи

Скобочный одночлен — выражение вида $[[x_1,x_2],[x_3,x_4]]$: каждая буква один раз, скобки расставлены полностью. Его форма $\sigma$ — неупорядоченное бинарное дерево (буквы стёрты, порядок детей не важен). Одночлен формы $\sigma$ обозначается $w_\sigma$.

**Гипотеза.** Если тождества $w_\sigma=0$ и $w_\tau=0$ равносильны в классе алгебр Ли, то $\sigma=\tau$.

В тетради условие записано как «одночлены равны в свободном коммутативном неассоциативном группоиде»; читать это нужно с точностью до переименования букв, иначе утверждение неверно уже при $n=3$.

Три равносильных вида гипотезы:

1. Идеалы. Пусть $F$ — свободная алгебра Ли, $I_\sigma$ — оболочка значений $w_\sigma$; тогда $I_x=F$, $I_{[\alpha,\beta]}=[I_\alpha,I_\beta]$. Гипотеза: разные формы дают разные идеалы. Иначе: подгруппоид идеалов, порождённый $F$ относительно $(A,B)\mapsto[A,B]$, свободен.
2. Однозначность разложения: из $[A,B]=[C,D]$ для идеалов вида $I_\sigma$ следует $\{A,B\}=\{C,D\}$.
3. Подпространства. Пусть $M_\sigma\subseteq\mathrm{Lie}(n)$ — оболочка всех одночленов формы $\sigma$ в полилинейной части. Тождество $w_\tau=0$ следует из $w_\sigma=0$ тогда и только тогда, когда $M_\tau\subseteq M_\sigma$. Гипотеза: подпространства разных форм различны.

## Что известно

- Задача стоит в тетради без отметки о решении. Поиск в открытом доступе решения не дал; MathSciNet и zbMATH не проверены.
- Счёт: для всех $n\le8$ (форм 1, 1, 2, 3, 6, 11, 23) подпространства $M_\sigma$ попарно различны. Размерности при этом иногда совпадают (при $n=6$ две формы с 75, при $n=8$ четыре таких пары).
- Шаг Якоби: поддерево $[[a,b],c]$ заменяется парой $[[a,c],b]$, $[a,[b,c]]$; получаются формы $\tau_1,\tau_2$ с $I_\sigma\subseteq I_{\tau_1}+I_{\tau_2}$. Отсюда отношение выводимости $\sigma\preceq\rho$, и из $\sigma\preceq\rho$ следует $M_\sigma\subseteq M_\rho$.
- Наблюдение J1: для $n\le8$ все включения $M_\sigma\subseteq M_\rho$ выводятся шагами Якоби (следований 1, 3, 9, 28, 90 при $n=4,\dots,8$ — столько же, сколько выводимых).
- Наблюдение J2: для $n\le17$ никакие две разные формы не выводятся друг из друга. J1 и J2 вместе дают гипотезу.
- Инварианты формы, читаемые по $M_\sigma$: высота дерева (через теорему Пуанкаре–Биркгофа–Витта, доказано) и число Стралера (номер последнего члена производного ряда, содержащего $I_\sigma$; есть набросок доказательства).

- **Доказано для $n\le12$** (12/10/2026; `checks/thin_search.py`, сертификат `thin_certificates.json`): тождества разных форм не равносильны. Метод — тонкие алгебры Ли: базис $e_u$, $u\in\mathbb Z^r$, скобка $[e_u,e_v]=c(u,v)\,e_{u+v}$ (кососимметричная целочисленная форма; скобка Пуассона мономов Лорана $x^iy^j$). Раскраска листьев формы в $r$ цветов даёт инвариант $\mathrm{Inv}_c(\sigma)$ — наборы цветов, при которых какая-то раскраска не зануляет ни одну вершину; из $M_\sigma\subseteq M_\tau$ следует $\mathrm{Inv}_c(\sigma)\subseteq\mathrm{Inv}_c(\tau)$. Для каждого $n\le12$ найдено несколько тонких алгебр (при $n=10$ восемь, при $n=11$ и $12$ одни и те же девять), инварианты которых различают все формы. Проверка сертификата — перебор раскрасок без линейной алгебры: `python thin_search.py verify`. Характеристика 0.
- Для *систем* скобочных тождеств шагов Якоби не хватает (`checks/lattice.py`): при $n=7$ есть замкнутый относительно шагов набор из шести форм, из тождеств которого следует седьмое, $[[[F'',F],F],F]=0$, хотя ни из одной формы набора по отдельности оно не следует. Для одиночных форм J1 при этом держится; «решёточного» доказательства J1 через суммы и пересечения быть не может.
- Пересечение $M_\sigma$ с фильтрацией Пуанкаре–Биркгофа–Витта (по глубине буквы) больше наивного подсчёта (`checks/filtration.py`, $n\le7$) — предостережение для маршрута S.
- «Родовые» инварианты — графы-деревья с иерархией формы, раскраски алгебры Витта, общая симплектическая форма (`checks/thin_invariants.py`) — различают все формы при $n\le6$, но не при $n=7,8$; нужны специально подобранные вырожденные $c$.

Точность счёта: при $n\le6$ ранги посчитаны точно и сверены с полным перебором расстановок букв; при $n=7,8$ — по модулю простых $2^{61}-1$ и $2^{31}-1$. Сертификаты тонких алгебр от точности счёта не зависят.

## План

1. Проверить новизну: MathSciNet, zbMATH, книга Бахтурина «Тождества в алгебрах Ли» и его обзор 2021 года, аналог для групп (outer commutator words). Спросить И. Кайгородова.
2. Записать с доказательствами фундамент: идеал значений, $I_{[\alpha,\beta]}=[I_\alpha,I_\beta]$, теорема о сведении, лемма о трёх идеалах, формула позвоночника, лемма о числе Стралера. Отдать Аристотелю на проверку.
3. Расширить счёт: сертификаты тонких алгебр дальше $n=12$; таблицу следований до $n=9$–$11$ через неприводимые представления $S_n$, чтобы проверить там J1.
4. Комбинаторика: описать порядок выводимости на деревьях и доказать J2.
5. Алгебра, маршрут T: найти явное семейство тонких алгебр, различающее любые две формы (сначала посмотреть по сертификатам, какие именно $c$ работают), и доказать это для всех $n$. Параллельно — J1 для полинильпотентных форм или помеченная гипотеза (маршрут S).
6. Запись.

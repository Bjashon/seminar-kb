## Задача одной строкой

Формы $\sigma\ne\tau$ (неупорядоченные бинарные деревья) задают неравносильные тождества алгебр Ли $w_\sigma=0$, $w_\tau=0$. То же самое: идеалы $I_x=F$, $I_{[\alpha,\beta]}=[I_\alpha,I_\beta]$ свободной алгебры Ли попарно различны; то же самое: подпространства $M_\sigma\subseteq\mathrm{Lie}(n)$ попарно различны. Характеристика $0$. Формулировку в тетради нужно читать после отождествления всех букв (иначе она неверна при $n=3$).

## Как запускать

Python — из окружения бэкенда: `backend/.venv/Scripts/python.exe -X utf8` (без `-X utf8` кириллица в консоли падает).

```
cd projects/monomial-identities/checks
python thin_search.py verify            # сертификат n ≤ 12, несколько минут
python thin_search.py find 13           # искать сертификат дальше
python thin_search.py families 9 1500   # хватает ли одного семейства
python witt/witt_check.py 10            # одна алгебра Витта, n ≤ 10
python witt/separate_pair.py 4 "[x,[x,x]]" "[[x,x],x]"   # чем различаются две формы
python build_lecture_json.py ../../..   # пересобрать lecture.json после правки вопросов и карточек
node trees.test.mjs .                   # из корня репозитория: проверка калькулятора курса
```

Скриптам с рангами (`bahturin26.py`, `atlas.py`, `lattice.py`, `filtration.py`) нужны `python-flint` и `numpy`, которых в окружении нет: поставить в отдельную папку (`pip install --target <папка> python-flint numpy`) и указать её в `PYTHONPATH`.

Сканы DjVu: установлен DjVuLibre (`C:\Program Files (x86)\DjVuLibre`). Текст — `djvutxt.exe книга.djvu out.txt`; страницы без текстового слоя — `scratch/render_djvu.ps1` (делает PNG; у книги Бахтурина номер страницы DjVu на единицу больше печатного). Файлы с кириллицей в имени сначала скопировать под латинским именем.

Курс смотреть локально: `npm run build` в `frontend/`, затем `python -m uvicorn app.main:app --port 8011` в `backend/` (порт 8000 может быть занят другим проектом).

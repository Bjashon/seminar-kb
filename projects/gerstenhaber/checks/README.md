# Численные проверки к статье

Скрипты, которыми проверялись утверждения статьи `../Gerstenhaber.tex` до того, как они были доказаны на бумаге. Запускать из этой папки питоном из `backend/.venv` (нужен только стандартный Python 3.11+, внешних библиотек нет).

## `gerst_check.py` — базис свободной алгебры

Строит свободную унитальную обобщённую алгебру Герстенхабера на образующих `1, x_1, …, x_n` «в лоб»: все неассоциативные слова заданной компоненты (мультилинейной по `x` и с фиксированным числом скобок `beta`), все экземпляры определяющих тождеств в этой компоненте, ранг над `GF(1000003)`. Размерность компоненты = число слов − ранг. Её сравниваем с числом элементов `U` в этой компоненте. Отдельно так же проверяется свободная нечётная супералгебра Ли против множества `M`.

```
python gerst_check.py 2 3 odd      # n=2, beta<=3, все 4 расстановки чётностей
python gerst_check.py 3 2 odd      # n=3, beta<=2, все 8 расстановок
python gerst_check.py 3 2 even     # контроль: случай Кайгородова 2017 (обобщённые пуассоновы)
python gerst_check.py 2 3 odd lex  # тот же расчёт с шировским (лексикографическим) порядком слов
```

Результаты — в `basis_counts.txt`: во всех проверенных компонентах `dim = |U|` и `dim = |M|`. Колонка `nested squares` — сколько дал бы неправильный вариант `M` (в котором разрешены квадраты квадратов): он даёт лишние элементы, то есть определение `M` в статье существенно.

Проверенный объём: `n ≤ 3` образующих, `beta ≤ 4` скобок (для n=2) / `beta ≤ 2` (для n=3), все чётности.

## `jacobiator_check.py` — лемма о якобиаторе

Проверяет лемму 9(ii) статьи: формула
`J(a,b,xy) = J(a,b,x)y + (−1)^{(|a|+|b|)|x|} x J(a,b,y) − J(a,b,1) xy`
следует из одних только тождеств (3) и (5) (кососимметричность и правило Лейбница), **без** тождества Якоби. Для этого алгебра строится с `SKIP_JACOBI = True`, и левая минус правая часть приводится по модулю тождеств: получается ноль во всех 16 расстановках чётностей четырёх образующих. Лог — `jacobiator_all_parities.txt` (около минуты на случай).

В скрипте якобиатор записан как `K(x; b, c) = {b,{c,x}} − {{b,c},x} − (−1)^{‖b‖‖c‖}{c,{b,x}}`, то есть `J(b,c,x)` в обозначениях статьи.

## `formal_identities_check.py` — леммы 6, 7, 8 как формальные тождества

Формулы (7) и (8) статьи реализованы буквально внутри свободной суперкоммутативной алгебры с **формальными** символами: множители $g_i$ (элементы $\widehat{\mathfrak L}$), единица $g_0=1$ и символы скобок $B(i,j)=\{g_i,g_j\}$, на которые наложена только нечётная кососимметричность (в частности $\{1,1\}$ — настоящий нечётный символ). Никакого тождества Якоби и никаких соотношений между разными $B$ не используется, поэтому всё, что верно здесь, верно и в модельной алгебре статьи. Проверяются, с точными целыми коэффициентами, для всех чисел множителей $m,n,p\le 3$ и всех расстановок чётностей: суперсимметричность и совместимость с вычёркиванием единиц (лемма 6 (a), (b)), пункты (i)–(iii) леммы 6, кососимметричность (лемма 7) и правило Лейбница (лемма 8) — всего 39 200 тождеств, все выполнены. Контроль чувствительности: при намеренно испорченном коэффициенте члена с $\mathfrak D(1)$ или знаке члена $\mathfrak D(a)b$ проверка падает.

```
python formal_identities_check.py      # ~20 секунд
```

## Что проверено машинно, а что нет

- Машинно, двумя независимыми способами: размерности компонент свободной алгебры совпадают с $|U|$ (`gerst_check.py`) и формулы (7), (8) удовлетворяют всем тождествам, кроме Якоби (`formal_identities_check.py`); формула для якобиатора (лемма 9) выполнена во всех 16 случаях чётностей (`jacobiator_check.py`).
- Только «руками»: лемма 4 (ссылка на теорему Холла–Штерна о базисе свободной супералгебры Ли), индукция в лемме 5 и предложении 10, теорема 12 (абстрактное рассуждение по универсальному свойству) и подсчёт в теореме 14. Это короткие структурные рассуждения без знаков — именно их и стоит перечитать авторам.
- Формализация в Lean/Mathlib возможна в принципе, но это отдельный большой проект: в Mathlib сейчас нет супералгебр (суперкоммутативных алгебр, нечётных супералгебр Ли, супердифференцирований) и нет теоремы о базисе Холла для свободных супералгебр Ли, так что всё пришлось бы строить с нуля.

## Что скрипты не проверяют

Они проверяют равенства размерностей и одно тождество в малых компонентах. Доказательства в статье от них не зависят; скрипты нужны, чтобы вовремя ловить ошибку в знаке или в определении (`M`, `U`, порядок слов) — именно так были найдены проблемы исходного черновика.
